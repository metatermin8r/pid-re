Welcome To Pathways into Cheating!

Synopsis: This program will allow you to edit your Saved Game files for Pathways Into Darkness. (PID) If you haven’t seen PID, check it out! It's a great new game from Bungie Software with smooth-scrolling, texture-mapped graphics. However, this will not edit the saved game files for the demo.

Requirements:
System 7.
A saved game file from Pathways Into Darkness

How to Use:
This program is quite straightforward:

• launch the application.
• select open from the file menu.
• locate the saved game file you want to change.
• edit the file (see below)
• save your changes.
• move the file into the same folder as PID, and name it “Saved Games” (without the quotes)

Editing your games:

When you select a saved game file, a window will come up. A popup menu will allow you to select which saved game to edit. Double click an item to change it to something else. Click “Add Item” to add an item to your inventory. Click “Delete Item” to remove an item from your inventory. Type numbers in the vitality boxes to change them. Vitality can only be between 0 and 3276.

When editing an item, you will be presented with an option to edit the quantity if you’re editing ammo. For other items, it is not safe for you to edit the quantity. If you want to edit a crystal’s charge, use the “Recharge Crystals” option. (see below)

Note that you are not allowed to add rounds to Colt .45 magazines. This is because Pathways will crash if it actually tries to display the Colt .45 gun. (It was not anticipated that it would ever need the gun, since no ammo for it can be found in the game, so no shape was ever drawn for it.)

Shortcuts:
Note that there is a menu labeled “Quick Cheats”. This has many predefined cheats to make editing your file easier. Using these cheats, you can avoid a lot of the work in adding items individually. You can also do some actions that there is no other way to do. Here is a summary of the Quick Cheat menu:

• Moderate Cheats (if you just want to cheat a litte)
  • Increase Vitality: set vitality and max vitality to 40
  • Extra Walther Ammo: give 100 extra rounds of walther ammo.
  • Recharge Crystals: Reset the crystals to their maximum potential
  • Teach me to use a Walther: set skill level for Walter P4 to expert.
• Massive Cheats (if you want to really cheat)
  • Max out vitality: Set vitality to 3276
  • Arm me to the Teeth: Add enough weaponry to defeat an army.
  • Crystalize me: Add one of each type of crystal.
  • Gimme something to drink: Add one of each type of potion.
  • Reset Time: Set the Game time to Monday, 6:13am
  • Raise Skill Levels: Make you an expert with all the weapons.

There is also a menu to allow you to teleport to various interesting places in the pyramid.

You can also make your character “left-handed” by clicking in the left-handed checkbox. This will change the way PID draws your character’s hand while holding a knife or Walther P4.
