This is a BinHex 4.0 file of the saved game file for the game Pathway into Darkness of a character Yoyoboy with the following modification: 1638.4 Health points; expert in all weapons (already 8192 kill points in each category); in possesion of a MP-72 Grenade Launcher, an AK-47 Assault Rifle, the Alien (Ammo) Replication Cedar Box, Fragmentation Grenades (255 rounds), Projectile Grenades (255 rounds), AK-47 SABOT Ammo clips (255 rounds).

The MP-72 loaded with Fragmentation grenades acts like a Super Mini/Shotgun: it can damage/kill all monsters (except the Greater Nightmares, the Green Ooze Slime Monsters, and conditionally the Flamethrower monster and the Spirit of the Demon) in sight. It's a handy weapon against groups of monsters.
